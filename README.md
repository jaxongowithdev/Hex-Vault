# Larder Haven

A private kitchen catalog. Map pantry shelves, file staples, and find what you already have — fully offline.

## Overview

**App Name:** Larder Haven
**Subtitle:** Map your pantry shelves
**Category:** Food & Drink / Lifestyle
**Platform:** iOS (Flutter)
**Purpose:** Track jars, spices, grains, and dry goods by larder, zone, and bay so you restock with intention.

## Core Features

- Create larders with a shelf mark, kitchen zone, and bay
- File staples with aisle, count, stock status, notes, and an optional label photo
- Search across name, aisle, and notes
- Pin weekly staples
- Reshelve items between larders with a short history note
- Kitchen insights by aisle and zone
- Export / restore a JSON catalog
- Light, dark, and system themes
- 100% offline, no account

## Technical Stack

- Flutter 3.32 / Dart >=3.4
- SQLite (`larder_haven.db`)
- Material 3 with olive / terracotta / cream palette
- Fonts: Fraunces + Nunito
- Image picker, file picker, share_plus

## Navigation

- Kitchen — home pulse and quick actions
- Larders — all shelves
- Insights — aisle and zone snapshot
- Studio — theme and catalog backup
