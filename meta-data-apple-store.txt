APP NAME
Hex Vault

SUBTITLE
Map your dice chests

KEYWORDS
dice,rpg,mini,tabletop,chest,hex,vault,token,dungeon,offline

PROMOTION
Stage chests, log dice, and find any set before game night. Private, offline.

DESCRIPTION
Hex Vault is a table catalog for players who already own more dice than they can keep in their head.

Name every chest in the study — the travel tray, the mini case, the map tube — then file each piece where it actually lives. When you wonder if that galaxy d20 is still in the pouch, search once instead of emptying three boxes.

What you can do
• Create named chests with a mark, room, and slot or pocket
• File pieces by kind: dice, minis, cards, maps, tokens, books, bags, terrain, and tools
• Mark state as New, Inked, Primed, or Worn
• Attach a table photo from the camera or your album
• Bookmark the sets you always bring to the next session
• Move a piece from one chest to another and keep a short note
• See a vault snapshot: how many chests are in use, which kinds run deepest
• Export or restore the whole list as a JSON file

Why it is different
Hex Vault is not a character sheet and not a generic storage box. It is a table map. The language, layout, and states are written for players: chests instead of bins, pieces instead of items, session notes instead of packing labels.

Private by design
Everything stays on your iPhone. There is no account, no cloud sync, and no marketplace. Open the app at the table with no signal and the same chests are still there.

Who it is for
New players building a first dice bag, painters with more than one case, anyone tired of buying a third set of the same polyhedrals.

Hex Vault — know the chest before you roll.
